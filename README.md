📖 仓库简介
本仓库专注整理国内大学生高频编程考试题目，聚焦两大核心场景：
1. 大学生编程竞赛：针对高校认可度最高的蓝桥杯、团体程序设计天梯赛，汇总历年省赛、国赛真题，提供通俗易懂的思路解析、完整可运行代码、复杂度分析；
2. 高校保研机试：收集整理多所顶尖985高校计算机、软工、电信等专业保研复试机试、预推免机试真题，覆盖各校高频考点、特色题型，解决保研备考无真题、无题解的痛点。
所有题解摒弃晦涩学术表述，以「新手能看懂、考场能用上」为核心，适配零基础刷题、竞赛冲奖、保研复试突击等各类需求。

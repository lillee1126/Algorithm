# 单词计数

## 来源

- [pgcode：西北大学计算机考研复试机试真题](https://gitcode.com/2301_81739397/pgcode)
- [在线评测](https://pgcode.cn/)

## 题目

#### 题目描述
给定一个字符串，请计算其中一共包含多少个单词（假设连续的无空格字母即为一个单词）？

#### 输入格式
输入数据是一个长度为 ${L(0<L<1000)}$ 的字符串，其中只包含字母和空格。

#### 输出格式
请输出给定字符串一共包含的单词数。

#### 数据范围
${0 < L < 1000}$

#### 输入样例
```
Welcome to NWU
```

#### 输出样例
```
3
```

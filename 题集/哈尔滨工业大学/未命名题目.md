# 未命名题目

## 题目

#### 题目描述

求 $1$-$n$ 内的完数，所谓的完数是这样的数，它的所有因子相加等于它自身，比如 $6$ 有 $3$ 个因子 $1$，$2$，$3$，$1 + 2 + 3 = 6$，那么 $6$ 是完数。

即完数是等于其所有因子（除了它自己）相加和的数。

#### 输入格式

测试数据有多组，输入 $n$，$n$ 数据范围不大。

#### 输出格式

对于每组输入，请输出 $1$-$n$ 内所有的完数。

如有案例输出有多个数字，用空格隔开，输出最后不要有多余的空格。

#### 输入样例
```
6
```

#### 输出样例
```
6
```

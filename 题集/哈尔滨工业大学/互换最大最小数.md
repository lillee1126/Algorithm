# 互换最大最小数

## 来源

## 题目

#### 题目描述

输入一个数 $n$，然后输入 $n$ 个数值各不相同，调换数组中最大和最小的两个数，然后输出。

#### 输入格式

测试数据有多组，输入 $n$ $(1 \leq n \leq 20)$，接着输入 $n$ 个数。

#### 输出格式

对于每组输入，输出交换后的结果。

#### 输入样例
```
2
1 3
```

#### 输出样例
```
3 1
```

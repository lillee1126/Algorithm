# 预约资格判定

## 来源

- [pgcode：深圳大学计算机保研机试真题](https://gitcode.com/2301_81739397/pgcode)
- [在线评测](https://pgcode.cn/)

## 题目

#### 题目描述

某驾驶的预约资格是：在每 ${12}$ 天的周期内，总学时达到 ${10}$ 小时可以预约考科目 ${2}$。

练习每一小时计一学时，不足一小时计 ${0}$。

受限制，按实际练车时长计算学时（若练车不足一小时则不算一学时，例如练车 ${119}$ 分钟只算练车 ${1}$ 小时计 ${1}$ 学时）。

#### 输入格式

第一行输入 ${t}$，表示有 ${t}$ 个学员。

每个学员输入两行：

- 第 ${1}$ 行输入学员姓名和学员类型，其中学员类型用单个大写字母表示，${N}$ 表示普通学员，${V}$ 表示 VIP 学员。

- 第 ${2}$ 行输入 ${12}$ 天的每天练车时间（单位为分钟）。

依次类推输入下一个学员。

#### 输出格式

输出 ${t}$ 行，每行输出学员姓名和是否可以预约科目二，具体输出信息看样例

#### 数据范围

- ${t}$ 为整数，且 ${1 \leq t \leq 100}$。

- 学员姓名由字母组成，长度不超过 ${20}$。

- 每天练车时间为整数分钟，且 ${0 \leq \text{分钟数} \leq 1440}$（即不超过 ${24}$ 小时）。

#### 输入样例

```
3  
Wendy N  
30 30 40 60 60 40 60 70 100 80 30 40  
Sarah V  
170 80 90 50 60 90 240 0 40 60 30 166  
zhang V  
80 10 10 30 60 0 60 0 30 150 0 0  
0 10 10 0 0 10 0 20 0 0 150 160
```

#### 输出样例

```
Wendy not qualify  
Sarah qualify  
zhang not qualify
```

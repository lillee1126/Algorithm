# 带哨兵的顺序查找

## 来源

- [pgcode：深圳大学计算机保研机试真题](https://gitcode.com/2301_81739397/pgcode)
- [在线评测](https://pgcode.cn/)

## 题目

#### 题目描述

给出一个队列和要查找的数值，找出数值在队列中的位置（位置从1开始）。

要求使用带哨兵的顺序查找算法：把要查找的数值插入到队列头部作为哨兵，然后从队列末尾往前查找。如果在队列中找到则返回位置，如果查找不成功则输出"error"。

#### 输入格式

第一行输入整数 ${n}$，表示队列有 ${n}$ 个数据

第二行输入 ${n}$ 个正整数，用空格隔开

第三行输入整数 ${i}$，表示要查找的数值个数

接下来输入 ${i}$ 行，每行一个要查找的数值

#### 输出格式

输出 ${i}$ 行，每行输出一个查找结果（位置或"error"）

#### 数据范围

${1 \le n \le 1000}$

${1 \le i \le 100}$

#### 输入样例

```
8
33 66 22 88 11 27 44 55
3
22
11
99
```

#### 输出样例

```
3
5
error
```

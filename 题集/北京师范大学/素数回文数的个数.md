# 素数回文数的个数

## 来源

- [pgcode：北京师范大学计算机保研机试真题](https://gitcode.com/2301_81739397/pgcode)
- [在线评测](https://pgcode.cn/)

## 题目

#### 题目描述

求 $11$ 到 $n$ 之间（包括 $n$），既是素数又是回文数的整数有多少个。

#### 输入格式

一个大于 $11$ 小于 $10000$ 的整数 $n$。

#### 输出格式

$11$ 到 $n$ 之间的素数回文数个数。

#### 数据范围

$11 < n < 10000$

#### 输入样例1

```
23
```

#### 输出样例1

```
1
```

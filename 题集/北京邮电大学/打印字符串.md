## 题目

老师有一个问题想考考 $mabo$，但是 $mabo$ 不会，所以想请你来帮帮忙。

问题如下：

给一串字符串，统计其中某个字符的个数。

#### 输入格式

首先输入一个整数 $T$，表示一共有 $T$ 组数据 $0 < T <= 10$。

接下来每行一个字母 $x$ ($x$ 为 $'a'$ - $'z'$ 或者 $'A'$ - $'Z'$)。

然后下面一行输入一个字符串 $s$ ($0 < s$ 的长度 $< 1000$)。

#### 输出格式

统计这个字母在这个字符串中出现的次数

#### 输入样例

```
2
a
absd
b
bbssb
```

#### 输出样例

```
1
3
```

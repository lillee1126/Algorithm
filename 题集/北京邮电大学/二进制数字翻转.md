## 题目

#### 题目描述

输入数据组数 $ t $，

每组数据输入一个十进制数 $ x $（$ 0 < x < 2^{32} $），将其二进制位反转（共 $ 32 $ 位），然后输出对应的十进制数。

注意：

1. 反转的含义是：头尾互换，不是 $ 0 $ $ 1 $ 互换。

2. 反转后的数据为无符号整数。

#### 输入样例
```
2
2
3
```

#### 输出样例
```
1073741824
3221225472
```

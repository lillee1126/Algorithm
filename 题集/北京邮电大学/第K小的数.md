# 第K小的数

## 来源

- [pgcode：北京邮电大学计算机考研复试机试真题](https://gitcode.com/2301_81739397/pgcode)
- [在线评测](https://pgcode.cn/)

## 题目

#### 题目描述

查找一个数组的第 $K$ 小的数，注意同样大小算一样大。

 如 $2$ $1$ $3$ $4$ $5$ $2$ 第三小数为 $3$。

#### 输入格式

输入有多组数据。

每组输入 $n$，然后输入 $n$ 个整数 $(1<=n<=1000)$，再输入 $k$。

#### 输出格式

输出第 $k$ 小的整数。

#### 输入样例
```
6
2 1 3 5 2 2
3
```

#### 输出样例
```
3
```

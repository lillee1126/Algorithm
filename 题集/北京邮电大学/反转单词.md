# 反转单词

## 题目

给出一句英文句子(只由大小写字母和空格组成，不含标点符号，也不会出现连续的空格)，请将其中的所有单词顺序翻转

#### 输入格式

多组数据，以 $EOF$ 结束。

每行一句英文句子(确保只由大小写字母和空格组成，不含标点符号，也不会出现连续的空格，字符串总长度 $1000$ 以内)

#### 输出格式

每组数据输出一行，为反转后的字符串

#### 输入样例

```
It is a apple
```

#### 输出样例

```
apple a is It
```

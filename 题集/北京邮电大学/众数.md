## 题目

给定一个长度为 $N$ 的非降数列，求数列中出现次数最多的数。

如果答案不唯一，输出其中最小的数。

#### 输入格式

输入数据第一行是一个整数 $T(1 \leq T \leq 100)$，表示测试数据的组数。

对于每组测试数据:

第一行是一个正整数 $N(1 \leq N \leq 100)$，表示数列长度。

第二行有 $N$ 个整数，整数之间用空格隔开，所有的整数都不超过 $10^5$，表示这个数列。

#### 输出格式

对于每组测试数据，输出一个整数。

#### 输入样例

```
2
4
1 1 1 2
5
1 1 2 2 3
```

#### 输出样例

```
1
1
```

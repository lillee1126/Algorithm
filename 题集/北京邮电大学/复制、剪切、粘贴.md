## 题目

#### 题目描述

给定一个字符串 $s$，对齐进行若干次复制、剪切、粘贴操作，三种操作如下：

   1. `COPY l r`（$0 \leq l \leq r < n$），$n$ 代表 $s$ 串的长度。

      这个表示将 $s$ 串从 $l$ 到 $r$ 的序列复制到剪贴板 $t$ 里面，覆盖 $t$ 字符串。

      例如 $s$ 为 $abcde$，$t$ 为 $pqr$，执行 `COPY 1 2` 变为 $s$ 为 $abcde$， $t$ 为 $bc$。

   3. `CUT l r`（$0 \leq l \leq r < n$），$n$ 代表 $s$ 串的长度。

      这个表示将 $s$ 串从 $l$ 到 $r$ 的序列剪切到剪贴板 $t$ 里面(删除 $s$ 串中的 $l$ 到 $r$ 的序列)，覆盖 $t$ 字符串。

      例如 $s$ 为 $abcde$， $t$ 为 $pqr$，执行 `CUT 1 2` 变为 $s$ 为 $ade$，$t$ 为 $bc$。

   3. `PASTE p`（$0 \leq p < n$），$n$ 代表 $s$ 串的长度。

      这个表示将 $t$ 串插入到 $s$ 串 $p$ 位置的后面。

      $t$ 保持不变。

      例如 $s$ 为 $abcde$，$t$ 为 $pqr$，执行 `PASTE 1` 变为，$s$ 为 $abpqrcde$，$t$ 为 $pqr$。

#### 输入格式

输入正整数 $N$，表示 $N$ 例测试。

首先给你 $s$ 串，再给你一个 $m$，然后给你 $m$ 个操作。

#### 输出格式

对每个操作，输出操作后的 $s$ 串。

#### 输入样例
```
1
abcde
5
CUT 1 2
COPY 0 1
PASTE 1
PASTE 1
CUT 1 3
```

#### 输出样例
```
ade
ade
adade
adadade
aade
```

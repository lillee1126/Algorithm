# 最长平衡串

## 题目

#### 题目描述

给定只含 $0$ $1$ 的字符串，找出最长平衡子串的长度。

平衡串：包含 $0$ 和 $1$ 的个数相同。

#### 输入格式

输入一串 $0$ $1$ 字符串，字符串长度最大为 $100000$。

#### 输出格式

输出最长的平衡子串的长度。

#### 输入样例

```
101011000
```

#### 输出样例

```
8
```

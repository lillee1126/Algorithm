## 题目

#### 题目描述

给定一个在 $0$ 到 $2^{32}$ 范围内的整数，将其转换为二进制形式，然后逆序排列这个二进制序列，最后将逆序后的二进制序列转换回十进制并输出。

#### 输入格式

输入一个整数 $n$，满足 $0 \leq n < 2^{32}$。

#### 输出格式

输出逆序后的二进制序列所对应的十进制整数。

#### 输入样例
```
2
```

#### 输出样例
```
1073741824
```

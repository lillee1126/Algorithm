## 题目

#### 题目描述

设计一个二次方程计算器。

#### 输入格式

每个输入是关于 $x$ 的一个二次方程表达式，为了简单，每个系数都是整数形式。

#### 输出格式

每个案例输出两个实数(由小到大输出，中间由空格隔开)，保留两位小数；如果无解，则输出 $No Solution$。

#### 输入样例

```
x^2+x=3x+4
```

#### 输出样例

```
-1.24 3.24
```

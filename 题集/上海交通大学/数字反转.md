## 题目

#### 题目描述

$12$ 翻一下是 $21$，$34$ 翻一下是 $43$，$12+34$ 是 $46$，$46$ 翻一下是 $64$，现在又任意两个正整数，问他们两个数反转的和是否等于两个数的和的反转。

#### 输入格式

每组数据输出一行一个结果，如果 $a+b$ 的反转的和等于 $a+b$ 的和的反转，则输出 $a+b$，否则输出 `NO`。

#### 输出格式

如果满足题目的要求输出 $a+b$ 的值，否则输出 NO。

#### 数据范围

$1≤a,b≤10000$

#### 输入样例

```
12 34
99 1
```

#### 输出样例

```
46
NO
```

# 力扣 172. 阶乘后的零（思维）2025人工智能学院硕士机试

## 题目与题解

[题目传送门](https://leetcode.cn/problems/factorial-trailing-zeroes/)
```cpp
class Solution {
public:
    int trailingZeroes(int n) {
        int ans=0;//2,5
        //5 10 15 20 25 30
        //
        for(int i=1;i<=n;i++){
            if(i%5==0){
                int t=i;
                while(t%5==0){
                    ans++;
                    t/=5;
                }
            }
        }
        return ans;
    }
};
```

# 后缀子串排序

## 题目

#### 题目描述

对于一个字符串，将其后缀子串进行排序。

例如字符串 $ grain $ 的后缀子串有：$ grain $、$ rain $、$ ain $、$ in $、$ n $。

然后对各子串按字典顺序排序，即：$ ain $、$ grain $、$ in $、$ n $、$ rain $。

#### 输入格式

多组数据输入。

每个案例为一行字符串。

#### 输出格式

将子串排序后输出，每个子串占一行。

#### 输入样例

```
grain
```

#### 输出样例

```
ain
grain
in
n
rain
```

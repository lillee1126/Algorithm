# 最长公共无数字子串

## 来源

- [pgcode：上海交通大学计算机保研机试真题](https://gitcode.com/2301_81739397/pgcode)
- [在线评测](https://pgcode.cn/)

## 题目

#### 题目描述

求两个字符串的最长公共子序列，要求该子串中不包含 $数字$。

#### 输入格式

输入两个字符串，每个字符串占一行。

#### 输出格式

输出最长公共无 $数字$ 子串。

如果有多个满足条件的最长子串，输出任意一个即可。

#### 输入样例

```
aa
ab
ab123abccff
abcfac123
```

#### 输出样例

```
a
abc
```

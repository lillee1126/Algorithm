# 最长连续递增序列

## 题目

#### 题目描述

给定一个未经排序的整数数组，找到最长且连续递增的子序列，并返回该序列的长度。

连续递增的子序列可以由两个下标 $l$ 和 $r$ ($l < r$) 确定，如果对于每个 $l <= i < r$，都有 $nums[i] < nums[i + 1]$，那么子序列 $[nums[l], nums[l + 1], ..., nums[r - 1], nums[r]]$ 就是连续递增子序列。

#### 输入格式

第一行输入一个整数 $n$ 表示数组的长度。

第二行输入 $n$ 个数 $nums[i]$。

($1 <= n <= 10^4$, $-10^9 <= nums[i] <= 10^9$)

#### 输出格式

输出最长连续递增子序列长度。

#### 输入样例

```
5
1 3 5 4 7
```

#### 输出样例

```
3
```

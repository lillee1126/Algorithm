# 正方形数组的数目

## 题目

#### 题目描述

给定一个非负整数数组 $A$，如果该数组每对相邻元素之和是一个完全平方数，则称这一数组为正方形数组。

返回 $A$ 的正方形排列的数目。

两个排列 $A1$ 和 $A2$ 不同的充要条件是存在某个索引 $i$，使得 $A1[i] \neq A2[i]$。

#### 输入格式

第一行输入一个整数 $n$ 表示数组的长度。

第二行输入 $n$ 个数表示数组的值。

$1 \leq A.length \leq 12$，$0 \leq A[i] \leq 1e9$。

#### 输出格式

输出正方形数组排列的数目。

#### 输入样例

```
3
1 17 8
```

#### 输出样例

```
2
```

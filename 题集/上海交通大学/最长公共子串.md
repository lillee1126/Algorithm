# 最长公共子串

## 来源

- [pgcode：上海交通大学计算机考研复试机试真题](https://gitcode.com/2301_81739397/pgcode)
- [在线评测](https://pgcode.cn/)

## 题目

#### 题目描述

给定两个字符串，求这两个字符串的**不包含数字**的最长公共子串。

#### 输入格式

共两行，每行一个由小写字母和数字构成的字符串。

#### 输出格式

若有多个答案，输出序列靠前的答案

#### 输入样例

```
ab123abccff
abcfac123
```

#### 输出样例

```
abc
```

# 棋盘遍历问题

- [pgcode：上海交通大学计算机保研机试真题](https://gitcode.com/2301_81739397/pgcode)
- [在线评测](https://pgcode.cn/)

## 题目

#### 题目描述

一个棋子从左上角出发，问能否遍历整个棋盘一次再回到起点，不允许重复访问同一格子。

如果可以遍历输出 $ Y $，否则输出 $ N $。

#### 输入格式

多组输入。

每组输入包含两个整数 $ N $ 和 $ M $，表示棋盘的大小，其中 $ N,M <= 10 $。

#### 输出格式

对于每组输入，输出结果，可以遍历输出 $ Y $，不能遍历输出 $ N $。

#### 输入样例

```
1 2
```

#### 输出样例

```
N
```

# 成绩排序

## 题目

输入 $n$ 个成绩，输出第 $x$ 小的成绩。

成绩排名从 $1$ 开始。

#### 输入格式说明

第一行：一个整数 $n$，代表成绩数量。

第二行：$n$ 个整数，代表每一个成绩。

第三行：一个整数 $x$，代表需要求的名次。

#### 输出格式说明

一个整数：第 $x$ 小的成绩。

#### 输入样例
```
5
1 2 2 3 4
3
```
#### 输出样例
```
2
```
#### 输入样例
```
5
5 5 5 4 4
5
```
#### 输出样例
```
5
```
#### 数据范围
$n$: [$1$， $1000$]，成绩：[$0$， $100$]，$x$：[$1$， $n$]

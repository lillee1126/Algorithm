# 最大子序列的和

## 题目

输入 $n$ 个整数，求出该数组中最大连续子序列的和，并输出该子序列的首尾位置。

序列位置从 $1$ 开始计数。

#### 输入格式说明

第一行：一个整数 $n$，代表序列中数字个数。

第二行：$n$ 个整数。

#### 输出格式说明

$3$ 个整数，分别是最大子序列和，子序列首位置，子序列尾位置。

#### 输入样例
```
8
1 -3 7 8 -4 12 -10 6
```

#### 输出样例
```
23 3 6
```

#### 数据范围
$n$：[ $1$， $1000$ ]，序列中的元素：[ $-1000$， $1000$ ]。

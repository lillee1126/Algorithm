# 拼出fudan

## 题目

#### 题目描述

给定一个字符串 ${s}$，只包含英文字母（大小写均有）。你可以使用字符串中的字母来拼出单词 "fudan"（不区分大小写，即可以使用 'F' 或 'f' 表示 'f'，以此类推）。每个字母在字符串中只能使用一次。问：最多能拼出多少个完整的 "fudan"？

#### 输入格式

- 一行字符串 ${s}$（长度范围：${1 \le |s| \le 1000}$），仅包含大小写英文字母。

#### 输出格式

- 一个整数，表示最多能拼出多少个完整的 "fudan"。

#### 数据范围

- ${1 \le |s| \le 1000}$

#### 输入样例1

```
FfuUddaANNn
```

#### 输出样例1

```
2
```

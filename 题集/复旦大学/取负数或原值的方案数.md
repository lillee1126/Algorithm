# 取负数或原值的方案数

## 来源

- [pgcode：复旦大学计算机保研机试真题](https://gitcode.com/2301_81739397/pgcode)
- [在线评测](https://pgcode.cn/)

## 题目

#### 题目描述

给定一个非负整数序列 $x_1, x_2, \dots, x_n$，可以给每一个整数取负数或者取原值。

求有多少种取法使得这些整数的和等于期望值 $E$。

结果对 $10^9 + 7$ 取模。

#### 输入格式

第一行包含两个整数 $N$ 和 $E$，分别表示序列长度和期望值。

第二行包含 $N$ 个非负整数，表示序列 $x_1, x_2, \dots, x_n$。

#### 输出格式

输出一个整数，表示满足条件的方案数，结果对 $10^9 + 7$ 取模。

#### 输入样例

```
5 3
1 1 1 1 1
```

#### 输出样例

```
5
```

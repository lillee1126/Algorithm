# 最大连续子序列和

## 来源

- [pgcode：复旦大学计算机保研机试真题](https://gitcode.com/2301_81739397/pgcode)

## 题目

#### 题目描述

给定一个数组及其大小，数组元素在 $[-10, 10]$，元素个数最多 $10^6$ 个。

输出最大的连续字串和，题目保证最后结果为正数。

#### 输入格式

输入包含一个数组及其大小。

#### 输出格式

输出最大的连续子串的和。

#### 输入样例

```
5
1 -2 3 5 -1
```

#### 输出样例

```
8
```

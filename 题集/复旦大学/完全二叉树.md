## 题目

#### 题目描述

给定一颗二叉树，树的每个节点的值为一个正整数。

如果从根节点到节点 $N$ 的路径上不存在比节点 $N$ 的值大的节点，那么节点 $N$ 被认为是树上的关键节点。

求树上所有的关键节点的个数。

请写出程序，并解释解题思路。

#### 输入样例

```
3 1 4 3 null 1 5
```

#### 输出样例

```
4
```

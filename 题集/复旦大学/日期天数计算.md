# 日期天数计算

## 来源

- [pgcode：复旦大学计算机保研机试真题](https://gitcode.com/2301_81739397/pgcode)
- [在线评测](https://pgcode.cn/)

## 题目

#### 题目描述

输入一个日期，格式为 $YYYYMMDD$，求该日期与 $20190205$ 相隔的天数。

#### 输入格式

输入一个日期，格式为 $YYYYMMDD$。

#### 输出格式

输出该日期与 $20190205$ 相隔的天数。

#### 输入样例

```
20190208
```

#### 输出样例

```
3
```

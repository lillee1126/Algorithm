# 二叉树最大叶子间距

## 来源

- [pgcode：复旦大学计算机保研机试真题](https://gitcode.com/2301_81739397/pgcode)
- [在线评测](https://pgcode.cn/)

## 题目

#### 题目描述

给定一棵二叉树，每个节点有一个唯一的编号。

给出每个节点的左右子树的编号（用 $-1$ 表示空），求这棵二叉树中两个叶子节点之间的最大间距。

#### 输入格式

第一行包含一个整数 $N$，表示二叉树的节点数量。

接下来的 $N$ 行，每行包含两个整数，表示对应节点的左子树编号和右子树编号（用 $-1$ 表示空）。

#### 输出格式

输出一个整数，表示二叉树中两个叶子节点之间的最大间距。

#### 输入样例 1

```
3
1 2
-1 -1
-1 -1
```

#### 输出样例 1

```
2
```

#### 输入样例 2

```
6
1 -1
2 3
4 -1
-1 5
-1 -1
-1 -1
```

#### 输出样例 2

```
4
```

# 计算学习时间

## 题目

#### 题目描述

小明每周的每一天都会去实验室，他严格设置了一周中每一天到达与离开实验室的时间，且一个学期中的每一周都遵循这样的时间安排。

一天中的午饭和晚饭时间是固定的，分别是 $12:00$ - $13:00$ 和 $17:00$ - $18:00$，在午饭和晚饭时间中小明是不学习的，其他时间内小明都在实验室内学习。

请你计算一个学期内小明的总学习时间（分钟）。

#### 输入格式

第一行：学期数。

第二行：一个学期的天数，该学期第一天是星期几。

第三行到第九行：周一到周日小明到达实验室与离开实验室的时间（$小时:分钟$）。

剩下为不同学期的时间信息，格式与前几行一样。

#### 输出格式

总时间（分钟）。

#### 输入样例

```
1
7 1
08:00 12:00
08:00 12:00
08:00 12:00
08:00 12:00
08:00 12:00
08:00 12:00
08:00 12:00
```

#### 输出样例

```
1680
```

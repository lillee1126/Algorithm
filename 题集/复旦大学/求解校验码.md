## 题目

#### 题目描述

给定一个 $9$ 位数字的 $ISBN$，求其校验位。

$ISBN$ 格式为 $2-02-033598$，校验位的计算方法如下：从左到右依次将各位数字乘 $10$，$9$，$8$，……，$2$，求出其和 $S$，作模运算得 $M = S \mod 11$。

若 $11 - M$ 在 $1$ 和 $9$ 之间，校验位即为该数字；若 $11 - M$ 等于 $10$，校验位为 $X$；若 $11 - M$ 等于 $11$，校验位为 $0$。

输出添加校验位的 $ISBN$，如 $2-02-033598-0$。

#### 输入格式

给定一个 $9$ 位数字的 $ISBN$

#### 输出格式

输出添加校验位的 $ISBN$

#### 输入样例

```
2-02-033598
```

#### 输出样例

```
2-02-033598-0
```

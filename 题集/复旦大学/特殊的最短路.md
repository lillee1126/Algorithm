# 特殊的最短路

## 来源

## 题目

#### 题目描述

给定一个有向图，节点编号为非负整数，图中每条边有一个正整数长度。对于从起点 $s$ 到节点 $t$ 的任意一条简单路径（路径中不重复经过节点），其“特殊距离”定义为：

特殊距离 = (路径上所有边的长度总和) + (路径上的最短边长度) - (路径上的最长边长度)

请计算起点 $s$ 到图中所有其他节点的最短特殊距离。若节点不可达，输出 -1。

#### 输入格式

第一行包含两个整数 $N$ 和 $M$ ($1 \leq N < 10^5$, $1 \leq M \leq 3 \times 10^5$)，分别表示节点数和边数。

接下来 $M$ 行，每行包含三个整数 $u, v, w$，表示一条从 $u$ 到 $v$ 的有向边，长度为 $w$ ($1 \leq w \leq 10^4$)。

最后一行包含一个整数 $s$，表示起点 ($0 \leq s < N$)。

#### 输出格式

共 $N$ 行，第 $i$ 行表示起点 $s$ 到节点 $i$ 的最短特殊距离。若不可达，输出 -1。

#### 数据范围

- $1 \leq N < 10^5$

- $1 \leq M \leq 3 \times 10^5$

- $1 \leq w \leq 10^4$

- $0 \leq s < N$

#### 输入样例1

```
3 3  
0 1 5  
0 2 10
1 2 3
0
```

#### 输出样例1

```
0
5
6
```

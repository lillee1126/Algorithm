## 题目

#### 题目描述

给定⼀个⻓为 $n$ 的序列 $A$，其中序列中的元素都是 $0$~$9$ 之间的整数，对于⼀个⻓度同样为 $n$ 整数序列 $B$，定义其权值为 $|A_i-B_i|$ $(1 \leq i \leq n)$ 之和加上 $(B_j-B_{j+1})^2$ $(1 \leq j < n)$ 之和。

求所有⻓为 $n$ 的整数序列中，权值最⼩的序列的权值是多少。

#### 输入格式

第⼀⾏⼀个整数 $n$ $(1 \leq n \leq 10^5)$，表⽰序列 $A$ 的⻓度。

第⼆⾏ $n$ 个整数 $a_1$， $a_2$， …， $a_n$ $(0 \leq a_i \leq 9$， $1 \leq i \leq n)$，表⽰序列 $A$ 中的元素。

#### 输出格式

仅⼀⾏⼀个整数，表⽰答案。

#### 输入样例

```
6
1 4 2 8 5 7
```

#### 输出样例

```
11
```

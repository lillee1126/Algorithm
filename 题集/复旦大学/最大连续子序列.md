# 最大连续子序列

## 来源

- [pgcode：复旦大学计算机考研复试机试真题](https://gitcode.com/2301_81739397/pgcode)

## 题目

#### 题目描述

给定一个数字序列 $A1$，$A2$…$An$，求 $i$，$j$ $(1 \leq i \leq j \leq n)$，使得 $Ai + … + Aj$ 最大，输出这个最大和。

#### 输入格式

第一行输入一个整数 $n$，表示数列大小

第二行输入 $n$ 个整数

#### 输出格式

最大和

#### 输入样例

```
6
-2 11 -4 13 -5 -2
```

#### 输出样例

```
20
```

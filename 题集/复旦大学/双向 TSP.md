# 双向 TSP

## 来源

- [pgcode：复旦大学计算机保研机试真题](https://gitcode.com/2301_81739397/pgcode)
- [在线评测](https://pgcode.cn/)

## 题目

#### 题目描述

对原始 $TSP$ 问题加上限制条件，地点的坐标为二维的，旅行商只能从左到右走，然后再从右到左回到起点，求最短的路径。

#### 输入格式

地点地址（地点横坐标互不相同，地点数量少于 $1000$）

#### 输出格式

最短路径

#### 输入样例

```
1 2
3 4
5 6
```

#### 输出样例

```
11.314
```

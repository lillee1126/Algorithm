## 题目

#### 题目描述

在一个无限大的棋盘上，安放了若干皇后。每个皇后可以攻击到其所在位置的行、列以及两条对角线上的其他皇后。现在需要将这些皇后划分为两个阵营A阵营和B阵营，满足以下条件：

1. 同一阵营内的皇后不能互相攻击（即同一阵营内任意两个皇后不能在同一行、同一列或同一条对角线上）

2. 不同阵营的皇后可以互相攻击（无限制）

3. 每个阵营至少包含一个皇后

给定所有皇后的坐标，计算满足上述条件的阵营划分方案总数。

#### 输入格式

- 第一行：一个整数 $n$（$1 \leq n \leq 10^5$），表示皇后的数量

- 接下来 $n$ 行：每行两个整数 $x_i$ 和 $y_i$（$-10^9 \leq x_i, y_i \leq 10^9$），表示第 $i$ 个皇后的坐标

  注意：保证所有皇后的坐标互不相同

#### 输出格式

- 一个整数，表示满足条件的阵营划分方案总数

- 由于结果可能很大，请输出对 $10^9+7$ 取模后的结果

#### 数据范围

$1 \leq n \leq 10^5$，坐标范围 $-10^9 \leq x_i, y_i \leq 10^9$

#### 输入样例1

```
3
0 0
0 1
1 0
```

#### 输出样例1

```
2
```

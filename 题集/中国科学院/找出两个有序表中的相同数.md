# 找出两个有序表中的相同数

## 来源

- [pgcode：中国科学院计算机保研机试真题](https://gitcode.com/2301_81739397/pgcode)
- [在线评测](https://pgcode.cn/)

## 题目

#### 题目描述

给定两个有序表，找出两个表中相同的数并打印出来。

#### 输入格式

输入包含两行，每行是一个有序表，表中的数按升序排列，数与数之间用空格分隔。

#### 输出格式

输出两个有序表中相同的数，按升序排列，数与数之间用空格分隔。

#### 输入样例

```
1 2 3 4 5
3 4 5 6 7
```

#### 输出样例

```
3 4 5
```

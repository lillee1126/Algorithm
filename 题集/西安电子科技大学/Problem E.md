# Problem E

## 题目

#### 题目描述
请写一个程序，判断给定表达式中的括号是否匹配，表达式中的合法括号为 "${(}$", "${)}$", "${[}$", "${]}$", "${}$", "${\}}$"，这三个括号可以按照任意的次序嵌套使用。

#### 输入格式
有多个表达式，输入数据的第一行是表达式的数目，每个表达式占一行。

#### 输出格式
对每个表达式，若其中的括号是匹配的，则输出 "${yes}$"，否则输出 "${no}$"。

#### 数据范围
表达式数目和长度未指定，但保证输入合法。

#### 输入样例
```
4
[(d+f)*{}]
[(2+3))
()}
[4(6]7)9
```

#### 输出样例
```
yes
no
no
no
```

# 跳一跳

## 题目

#### 题目描述
最近很火的微信游戏跳一跳游戏规则如下：短跳得 ${1}$ 分，跌落游戏结束，长跳得 ${2}$ 分，并且长跳可连续累加，第一次 ${2}$ 分，第二次 ${4}$ 分，第三次 ${6}$ 分，依次类推，若长中断则重新计分。 

现给定 ${0, 1, 2}$ 的组合序列，其中 ${0}$：跌落，${1}$：短跳成功，${2}$：长跳成功。 

请你计算玩家当次游戏的合计得分。

#### 输入格式
多组数据输入。 

首先输入一个数字 ${n}$（${n \leq 100}$）代表当前游戏状态变化数，接着输入 ${n}$ 个由 ${0, 1, 2}$ 组合的数字，${0}$ 代表结束。

#### 输出格式
输出玩家当次游戏得分。

#### 数据范围
${n \leq 100}$

#### 输入样例
```
6
1 2 2 1 2 0
```

#### 输出样例
```
10
```

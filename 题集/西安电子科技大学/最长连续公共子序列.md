# 最长连续公共子序列

## 来源

- [pgcode：西安电子科技大学计算机保研机试真题](https://gitcode.com/2301_81739397/pgcode)
- [在线评测](https://pgcode.cn/)

## 题目

#### 题目描述

输入两个字符串 $s1$, $s2$。

输出最长连续公共子串长度和最长连续公共子串。

#### 输入格式

多组数据输入。

输入两个字符串 $s1$, $s2$, 长度不大于 $100$, 以空格隔开。

#### 输出格式

输出最长连续公共子串长度和最长连续公共子串。

#### 输入样例
```
abcdefg qwercdefiok
```

#### 输出样例
```
4
cdef
```

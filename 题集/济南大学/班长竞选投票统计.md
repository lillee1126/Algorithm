# 班长竞选投票统计

## 来源

## 题目

#### 题目描述

$3$ 名同学（编号 $1$、$2$、$3$）竞选班长，$22$ 名同学投票。

统计得票最高的同学编号（如有多人票数相同，输出编号最小的）。

#### 输入格式

一行 $22$ 个整数（每个整数是 $1$、$2$ 或 $3$），表示投票结果。

#### 输出格式

一行一个整数，表示得票最高的同学编号。

#### 输入样例
```
1 2 3 1 2 3 1 2 3 1 2 3 1 2 3 1 2 3 1 2 3 1
```

#### 输出样例
```
1
```

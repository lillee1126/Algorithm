# 特殊数字筛选

## 来源

## 题目

#### 题目描述

输出 $n$ 以内能被 $3$ 整除且除以 $5$ 余 $1$ 的所有正整数，数字间用单个空格分隔（末尾无空格）。

#### 输入格式

$n$

#### 输出格式

一行整数，空格分隔

#### 输入样例

```
200
```

#### 输出样例
```
6 21 36 51 66 81 96 111 126 141 156 171 186
```

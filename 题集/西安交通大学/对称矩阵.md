# 对称矩阵

## 来源

- [pgcode：西安交通大学计算机考研复试机试真题](https://gitcode.com/2301_81739397/pgcode)
- [在线评测](https://pgcode.cn/)

## 题目

#### 题目描述
输入一个 ${N}$ 维矩阵，判断是否对称。

#### 输入格式
输入第一行包括一个数：${N(1 \le N \le 100)}$，表示矩阵的维数。
接下来的 ${N}$ 行，每行包括 ${N}$ 个数，表示 ${N \times N}$ 矩阵的元素。

#### 输出格式
可能有多组测试数据，对于每组数据，
输出 "Yes!" 表示矩阵为对称矩阵。
输出 "No!" 表示矩阵不是对称矩阵。

#### 数据范围
${1 \le N \le 100}$

#### 输入样例
```
4
16 19 16 6 
19 16 14 5 
16 14 16 3 
6 5 3 16 
2
1 2
3 4
```

#### 输出样例
```
Yes!
No!
```

# 差分计数

## 题目

给定 $n$ 个整数 $a_1, a_2, \ldots, a_n$ 和一个整数 $x$。

请你计算，一共有多少个有序对 $(i, j)$ 满足 $a_i - a_j = x$。

注意：

1. $i$ 和 $j$ 可以相等。

2. $(1, 2)$ 和 $(2, 1)$ 应视为两个不同的**有序**对。

#### 输入格式

第一行包含两个整数 $n$, $x$。

第二行包含 $n$ 个整数 $a_1, a_2, \ldots, a_n$。

#### 输出格式

一个整数，表示满足条件的有序对的数量。

#### 数据范围

$1 \leq n \leq 10^6$

$-10^6 \leq x, a_i \leq 10^6$

#### 输入样例
```
5 1
1 1 5 4 2
```

#### 输出样例
```
3
```

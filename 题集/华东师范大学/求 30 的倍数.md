# 求 30 的倍数

## 题目

#### 题目描述

就是输入一个数，比如 $201$，让数字随意组合，是否能组合出 $30$ 的倍数。

如果能够组合成 $30$ 的倍数，就输出最大的倍数，不能就输出 $-1$。

例如输入 $201$ 你可以随意组合成 $201$，$210$，$012$，$021$，$102$，$120$ 等数字。

其中 $120$，$210$ 都是 $30$ 的倍数，由于要找最大的，所以答案是 $210$。

#### 输入样例
```
201
```

#### 输出样例
```
210
```

# 判断字符串的子串是否由相同字符串拼接而成

## 来源

- [pgcode：中山大学计算机保研机试真题](https://gitcode.com/2301_81739397/pgcode)
- [在线评测](https://pgcode.cn/)

## 题目

#### 题目描述

输入字符串 $A$，判断 $A$ 是否存在子串 $A'$ 可由字符串 $B + B$ 组成。

（$B$ 未给出）例如 $A = \text{“ababc”}$，则存在子串 $A' = \text{“abab”}$，可由字符串 $B = \text{“ab”}$ 组成。

又如 $A = \text{“zaat”}$，则存在子串 $A' = \text{“aa”}$，可由字符串 $B = \text{“a”}$ 组成。

#### 输入格式

输入一个字符串 $A$。

#### 输出格式

如果存在符合条件的子串，输出 $\text{“YES”}$；否则输出 $\text{“NO”}$。

#### 输入样例
```
ababc
```

#### 输出样例
```
YES
```

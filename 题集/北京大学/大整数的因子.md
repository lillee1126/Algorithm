# 大整数的因子

## 题目

#### 题目描述

已知正整数 $ k $ 满足 $ 2 \leq k \leq 9 $，现给出长度最大为 $ 30 $ 位的十进制非负整数 $ c $，求所有能整除 $ c $ 的 $ k $。

#### 输入格式

若干个非负整数 $ c $，$ c $ 的位数 $ \leq 30 $

每行一个 $ c $

#### 输出格式

每一个 $ c $ 的结果占一行

1) 若存在满足 $ c \% k == 0 $ 的 $ k $，输出所有这样的 $ k $，中间用空格隔开，最后一个 $ k $ 后面没有空格。

2) 若没有这样的 $ k $ 则输出 "none"

注意整数溢出问题

不要对 $ -1 $ 进行计算

#### 输入样例
```
30
72
13
```

#### 输出样例
```
2 3 5 6
2 3 4 6 8 9
none
```

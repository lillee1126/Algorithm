# skew 数

## 题目

#### 题目描述

在 $skew binary$ 表示中，第 $k$ 位的值 $x[k]$ 表示 $x[k] \times (2^{k+1}-1)$。

每个位上的可能数字是 $0$ 或 $1$，最后面一个非零位可以是 $2$，例如，$10120(skew) = 1 \times (2^5-1) + 0 \times (2^4-1) + 1 \times (2^3-1) + 2 \times (2^2-1) + 0 \times (2^1-1) = 31 + 0 + 7 + 6 + 0 = 44$。

前十个 $skew$ 数是 $0$、$1$、$2$、$10$、$11$、$12$、$20$、$100$、$101$、以及 $102$。

#### 输入格式

输入包括多组数据，每组数据包含一个 $skew$ 数。

#### 输出格式

对应每一组数据，输出相应的十进制形式。

结果不超过 $2^{31}-1$。

#### 输入样例
```
10120
200000000000000000000000000000
10
1000000000000000000000000000000
11
100
11111000001110000101101102000
```

#### 输出样例
```
44
2147483646
3
2147483647
4
7
1041110737
```

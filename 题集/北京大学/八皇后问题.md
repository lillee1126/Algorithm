## 题目

#### 题目描述

在国际象棋中，皇后可以在 $横$、$竖$、$斜线$上不限步数地吃掉其他棋子。

如何将 $8$ 个皇后放在 $8 \times 8$ 的棋盘上，使它们互相不能攻击？这就是著名的八皇后问题。

对于每个满足要求的摆放方法，定义一个皇后串 $a = b_1 b_2 ... b_8$，其中 $b_i$ 表示第 $i$ 行皇后所在的列数。

已知 $8$ 皇后问题共有 $92$ 组解（即 $92$ 个不同的皇后串）。

给定一个数 $b$，要求输出第 $b$ 个皇后串。

皇后串的比较规则是：将串视为整数时，数值小的串排在前面。

#### 输入格式

每组测试数据占 $1$ 行，包括一个正整数 $b(1 \leq b \leq 92)$。

#### 输出格式

对于每个输入 $b$，输出一行，即对应的皇后串。

#### 输入样例

```
1
```

#### 输出样例

```
15863724
```

# 与 7 无关的数

## 来源

- [pgcode：北京大学计算机考研复试机试真题](https://gitcode.com/2301_81739397/pgcode)
- [在线评测](https://pgcode.cn/)

## 题目

#### 题目描述

一个正整数，如果它能被 $7$ 整除，或者它的十进制表示法中某个位数上的数字为 $7$，则称其为与 $7$ 相关的数。

现求所有小于等于 $n$ $(n<100)$ 的与 $7$ 无关的正整数的平方和。

#### 输入格式

案例可能有多组。

对于每个测试案例输入为一行，正整数 $n$ $(n<100)$。

#### 输出格式

对于每个测试案例输出一行，输出小于等于 $n$ 的与 $7$ 无关的正整数的平方和。

#### 输入样例
```
21
```

#### 输出样例
```
2336
```

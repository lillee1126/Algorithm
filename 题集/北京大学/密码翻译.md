# 密码翻译

## 题目

#### 题目描述

在情报传递过程中，为了防止情报被截获，需要对情报进行加密。

我们给出一种简单的加密方法：对给定的字符串，把其中从 $a$-$y$、$A$-$Y$ 的字母用其后继字母替代，把 $z$ 和 $Z$ 分别用 $a$ 和 $A$ 替代，从而得到加密字符串。

#### 输入格式

多组测试数据输入。

读取一行字符串，每个字符串长度小于 $80$ 个字符。

#### 输出格式

对于每组数据，输出加密后的字符串。

#### 输入样例

```
Hello! How are you!
```

#### 输出样例

```
Ifmmp! Ipx bsf zpv!
```

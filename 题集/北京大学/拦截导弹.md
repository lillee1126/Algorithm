# 拦截导弹

## 来源

- [pgcode：北京大学计算机保研机试真题](https://gitcode.com/2301_81739397/pgcode)
- [在线评测](https://pgcode.cn/)

## 题目

#### 题目描述

某国为了防御敌国的导弹袭击，开发出一种导弹拦截系统。

这种导弹拦截系统的第一发炮弹能够到达任意高度，但之后每一发炮弹都不能高于前一发的高度。

给定来袭导弹的高度序列（按袭击时间顺序），计算这套系统最多能拦截多少枚导弹。

拦截时必须按照导弹来袭的顺序进行。

#### 输入格式

- 第一行：导弹数量 $k$（$k \leq 25$）

- 第二行：$k$ 个正整数，表示导弹高度序列（以空格分隔）

#### 输出格式

- 一个整数，表示最多能拦截的导弹数量

#### 输入样例

```
8
300 207 155 300 299 170 158 65
```

#### 输出样例

```
6
```

（说明：最优拦截序列为 300, 207, 155, 170, 158, 65 或 300, 299, 170, 158, 65）

# 求平均年龄

## 来源

- [pgcode：北京大学计算机保研机试真题](https://gitcode.com/2301_81739397/pgcode)
- [在线评测](https://pgcode.cn/)

## 题目

#### 题目描述

班上有学生若干名，给出每名学生的年龄（整数），求班上所有学生的平均年龄，保留到小数点后两位。

#### 输入格式

第一行有一个整数 $n$ $(1 \leq n \leq 100)$，表示学生的人数。

其后 $n$ 行每行有 $1$ 个整数，取值为 $15$ 到 $25$。

#### 输出格式

对于每组数据，输出一行，该行包含一个浮点数，为要求的平均年龄，保留到小数点后两位。

#### 输入样例

```
2
18
17
```

#### 输出样例

```
17.50
```

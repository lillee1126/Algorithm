# 中位数

## 来源

- [pgcode：北京大学计算机考研复试机试真题](https://gitcode.com/2301_81739397/pgcode)
- [在线评测](https://pgcode.cn/)

## 题目

#### 题目描述

中位数定义：一组数据按从小到大的顺序依次排列，处在中间位置的一个数（或最中间两个数据的平均数）。

给出一组无序整数，求出中位数，如果求最中间两个数的平均数，向下取整即可（不需要使用浮点数）。

#### 输入格式

该程序包含多组测试数据，每一组测试数据的第一行为 $N$，代表该组测试数据包含的数据个数，$1 \leq N \leq 10000$。

接着 $N$ 行为 $N$ 个数据的输入，$N = 0$ 时结束输入。

#### 输出格式

输出每组数据的中位数。

#### 输入样例
```
4
10
30
20
40
3
40
30
50
4
1
2
3
4
0
```

#### 输出样例
```
25
40
2
```

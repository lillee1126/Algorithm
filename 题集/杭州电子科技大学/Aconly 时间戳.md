# Aconly 时间戳

## 题目

#### 题目描述

时间戳是自 $1970$ 年 $1$ 月 $1$ 日（$00:00:00$ $GMT$）以来的秒数。

然而 $Aconly$ 不喜欢这个东西，所以他制定了一种新的时间戳叫 $Aconly$ 时间戳，它是自 $2009$ 年 $1$ 月 $1$ 日（$00:00:00$ 北京时间）以来的秒数。

例如 $0$ 就是 $2009-01-01$ $00:00:00$ , $60$ 就是 $2009-01-01$ $00:01:00$。

#### 输入格式

有多组测试数据。

每组数据一个整数 $n$（$0 \leq n \leq 31535999$），即 $Aconly$ 时间戳。

#### 输出格式

输出相应的北京时间。

每组数据占一行。

#### 输入样例
```
0
60
10000000
31535999
```

#### 输出样例
```
2009-01-01 00:00:00
2009-01-01 00:01:00
2009-04-26 17:46:40
2009-12-31 23:59:59
```

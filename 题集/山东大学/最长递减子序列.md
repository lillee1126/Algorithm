# 最长递减子序列

## 来源

## 题目

#### 题目描述

输入数字 $n$，和 $n$ 个整数，输出该数字串中的最长递减序列。

#### 输入格式

第一行包含一个整数 $n$，表示数字的个数。

第二行包含 $n$ 个整数，表示数字串。

#### 输出格式

输出该数字串中的最长递减序列。

#### 输入样例
```
8
9 4 3 2 5 4 3 2
```

#### 输出样例
```
9 5 4 3 2
```

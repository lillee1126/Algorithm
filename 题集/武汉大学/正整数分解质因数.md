# 正整数分解质因数

## 来源

- [pgcode：武汉大学计算机保研机试真题](https://gitcode.com/2301_81739397/pgcode)
- [在线评测](https://pgcode.cn/)

## 题目

#### 题目描述

将一个正整数分解质因数。

例如：输入 $90$，打印出 $90 = 2 * 3 * 3 * 5$。

#### 输入格式

多组输入数据，每组数据为一个正整数。

#### 输出格式

输出该正整数的质因数分解结果，格式如 $2 * 3 * 3 * 5$。

如果输入数字本身是一个质数，则不输出任何结果。

#### 输入样例
```
10
90
```

#### 输出样例
```
2 * 5
2 * 3 * 3 * 5
```

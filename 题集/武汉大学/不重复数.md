# 不重复数

- [在线评测](https://pgcode.cn/)

## 题目

#### 题目描述

给定一个数，若该数的相邻数字都不相同，则称该数为不重复数（如 $110$ 为重复数，$101$ 为不重复数）。

输入 $n$，编程实现比 $n$ 大的最小不重复数。

#### 输入格式

多组数据输入。

#### 输出格式

输出比 $n$ 大的最小不重复数。

#### 输入样例
```
5
10
20
```

#### 输出样例
```
6
12
21
```

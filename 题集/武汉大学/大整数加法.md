# 大整数加法

## 来源

- [pgcode：武汉大学计算机考研复试机试真题](https://gitcode.com/2301_81739397/pgcode)
- [在线评测](https://pgcode.cn/)

## 题目

#### 题目描述

写程序求两个相同位数的大整数之和

#### 输入格式

多组数据输入，两个大整数 $($ 位数不超过 $1000)$

#### 输出格式

两个大整数的和

#### 输入样例
```
1234567890 1234567890
111111111111 222222222222
```

#### 输出样例
```
2469135780
333333333333
```

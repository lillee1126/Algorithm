# 组合数计算

## 来源

- [pgcode：西北工业大学计算机保研机试真题](https://gitcode.com/2301_81739397/pgcode)
- [在线评测](https://pgcode.cn/)

## 题目

#### 题目描述

计算从 $n$ 个数中任取 $m$ 个数的不同取法个数，即组合数 $C(n, m)$。

#### 输入格式

输入一行，包含两个整数 $n$ 和 $m$，用空格分隔。

#### 输出格式

输出一个整数，表示组合数 $C(n, m)$ 的值。

#### 输入样例
```
10 3
```

#### 输出样例
```
120
```

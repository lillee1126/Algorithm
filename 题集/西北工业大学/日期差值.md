# 日期差值

## 来源

- [pgcode：西北工业大学计算机考研复试机试真题](https://gitcode.com/2301_81739397/pgcode)

## 题目

#### 题目描述

有两个日期，求两个日期之间的天数，如果两个日期是连续的我们规定他们之间的天数为 $2$ 天

#### 输入格式

有多组数据，每组数据有两行，分别表示两个日期，形式为 $YYYYMMDD$

#### 输出格式

每组数据输出一行，即日期差值

#### 输入样例
```
20110412
20110422
```

#### 输出样例
```
11
```

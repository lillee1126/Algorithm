# 递推数列求模

## 题目

#### 题目描述

给定初始项 $ a_0 $、$ a_1 $，以及递推关系 $ a_n = p \times a_{n-1} + q \times a_{n-2} $（$ n \geq 2 $）。

给定参数 $ p $、$ q $ 和 $ k $，求第 $ k $ 项 $ a_k $ 对 $ 10000 $ 取模的结果。

#### 输入格式

输入包含 $ 5 $ 个整数：$ a_0 $、$ a_1 $、$ p $、$ q $、$ k $（$ 0 \leq a_0, a_1, p, q, k \leq 10000 $）。

#### 输出格式

输出一个整数，表示 $ a_k \mod 10000 $ 的结果。

#### 输入样例

```
20 1 1 14 5
```

#### 输出样例

```
8359
```

# 字符串解密

## 题目

#### 题目描述

现定义一种字符串加密方式：将字符串每个字符的值在字母表上向右移一位。

右移的规则是 $ a $ -> $ b $，$ b $ -> $ c $，...，$ y $ -> $ z $，$ z $ -> $ a $。

例如 $ "afju" $ 加密后为 $ "bgkv" $。

现给定正整数 $ n $（$ n \leq 1e18 $）和一个长度不超过 $ 1e6 $ 的只含小写字母的字符串 $ s $，已知 $ s $ 被加密了 $ n $ 次，输出加密前的字符串。

#### 输入格式

第一行包含一个正整数 $ n $（$ n \leq 1e18 $）。

第二行包含一个只含小写字母的字符串 $ s $（长度不超过 $ 1e6 $）。

#### 输出格式

输出解密后的原始字符串。

#### 输入样例

```
3
dliow
```

#### 输出样例

```
aiflt
```

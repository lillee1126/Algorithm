# 求最大最小数

## 来源

- [pgcode：清华大学计算机考研复试机试真题](https://gitcode.com/2301_81739397/pgcode)
- [在线评测](https://pgcode.cn/)

## 题目

#### 题目描述

输入 $ N $ 个（$ N <= 10000 $）数字，求出这 $ N $ 个数字中的最大值和最小值。

每个数字的绝对值不大于 $ 1000000 $。

#### 输入格式

输入包括多组测试用例，每组测试用例由一个整数 $ N $ 开头，接下去一行给出 $ N $ 个整数。

#### 输出格式

输出包括两个整数，为给定 $ N $ 个数中的最大值与最小值。

#### 输入样例

```
5
1 2 3 4 5
3
3 7 8
```

#### 输出样例

```
5 1
8 3
```

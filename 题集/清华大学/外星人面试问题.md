# 外星人面试问题

## 题目

#### 题目描述

有 $n$ 个外星人依次进行面试，要求找出至少 $m$ 个身高差不超过 $k$ 的人。

给定这 $n$ 个人的身高，输出需要面试的最少人数（注意是依次面试）。

#### 输入格式

第一行包含四个整数 $n$, $m$, $k$, $h_{\text{max}}$，分别表示外星人数量、需要选取的最少人数、允许的最大身高差和最大身高值。

第二行包含 $n$ 个整数，表示每个外星人的身高。

#### 输出格式

输出一个整数，表示需要面试的最少人数。

#### 输入样例

```
5 3 2 10
3 1 4 1 5
```

#### 输出样例

```
4
```

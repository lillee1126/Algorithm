## 题目

#### 题目描述

某个序列有 $n$ 个正整数，每个正整数都是 $m$ 位数。

某科研人员想统计该序列各个位的“众数”。

第 $i$ $(1 \leq i \leq m)$ 位的众数是指，$n$ 个正整数的第 $i$ 位出现次数最多的最小数字。

最低位（个位）是第 $1$ 位，最高位是第 $m$ 位。

#### 输入格式

输入的第一行包含两个正整数 $n$, $m$，保证 $n \leq 10^5$, $m \leq 6$。

输入的第二行包含 $n$ 个正整数。

同行相邻两个整数用一个空格隔开。

#### 输出格式

输出共 $m$ 行，每行一个整数，第 $i$ 行表示第 $i$ 位的众数。

#### 输入样例

```
3 3
120 120 120
```

#### 输出样例

```
0
2
1
```

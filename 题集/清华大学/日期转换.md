## 题目

#### 题目描述

自定义一种新的日期系统，其时间单位定义如下：

- 每天 $10$ 小时

- 每小时 $100$ 分钟

- 每分钟 $100$ 秒

- 每年 $10$ 个月

- 每月 $10$ 星期

- 每星期 $10$ 天

给定一个现实日期（公历日期），计算对应的自定义日期。

假设两种日期系统的起始点相同（即公元 $1$ 年 $1$ 月 $1$ 日对应自定义 $1$ 年 $1$ 月 $1$ 日 $1$ 时 $1$ 分 $1$ 秒）。

#### 输入格式

第一行一个整数 $n$, 表示要转换的数量。

接下来 $n$ 行，格式如下：$hour:minute:second day.month.year$ 表示常规的日期。日期总是合法的。2000 <= year <= 50000。

#### 输出格式

对应的自定义日期，格式为 $Y-M-D H:M:S$

#### 输入样例

```
7
0:0:0 1.1.2000
10:10:10 1.3.2001
0:12:13 1.3.2400
23:59:59 31.12.2001
0:0:1 20.7.7478
0:20:20 21.7.7478
15:54:44 2.10.20749
```

#### 输出样例

```
0:0:0 1.1.0
4:23:72 26.5.0
0:8:48 58.2.146
9:99:98 31.8.0
0:0:1 100.10.2000
0:14:12 1.1.2001
6:63:0 7.3.6848
```

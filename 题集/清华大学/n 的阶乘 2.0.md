## 题目

#### 题目描述

输入一个正整数 $N$，输出 $N$ 的阶乘。

#### 输入格式

正整数 $N$ ($0 \leq N \leq 1000$)

#### 输出格式

输入可能包括多组数据，对于每一组输入数据，输出 $N$ 的阶乘

#### 输入样例

```
4
5
15
```

#### 输出样例

```
24
120
1307674368000
```

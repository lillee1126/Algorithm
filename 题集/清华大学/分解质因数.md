# 分解质因数

## 题目

#### 题目描述

给定一个整数，将其分解质因数，并按从小到大的顺序输出质因数及其指数。

例如：$60 = 2^2 * 3^1 * 5^1$。

#### 输入格式

一个整数 $n$（$1 \leq n \leq 1e8$）。

#### 输出格式

输出形如 "$n = p1^e1 * p2^e2 * ... * pk^ek$" 的字符串，其中 $p1 < p2 < ... < pk$ 为质因数，$ei$ 为对应的指数。

若指数为 $1$，则省略 $^1$ 部分。

#### 输入样例

```
60
```

#### 输出样例

```
60 = 2^2 * 3 * 5
```

# 球的半径和体积

## 来源

- [pgcode：清华大学计算机考研复试机试真题](https://gitcode.com/2301_81739397/pgcode)
- [在线评测](https://pgcode.cn/)

## 题目

#### 题目描述

输入球的中心点和球上某一点的坐标，计算球的半径和体积

#### 输入格式

球的中心点和球上某一点的坐标，以如下形式输入：$x0$ $y0$ $z0$ $x1$ $y1$ $z1$

#### 输出格式

输入可能有多组，对于每组输入，输出球的半径和体积，并且结果保留三位小数

为避免精度问题，$PI$ 值请使用 $arccos(-1)$。

#### 输入样例

```
0 0 0 1 1 1
```

#### 输出样例

```
1.732 21.766
```

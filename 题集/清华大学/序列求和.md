# 序列求和

## 题目

#### 题目描述

给定正整数 $a$、$n$、$m$ 和所有 $b_i$ 的值，计算 $S(n)$ 的值。

由于结果可能很大，请输出其对 $10^9+7$ 取模的余数。

定义：

- $S(x) = a^x \times \left( \sum_{i=1}^m b_i \times x^i \right)$

#### 输入格式

第一行包含四个整数 $a$, $n$, $m$

第二行包含 $m$ 个整数，表示 $b_1$ 到 $b_m$

#### 输出格式

输出一个整数，表示 $S(n) \mod (10^9+7)$

#### 输入样例

```
2 3 2
1 2
```

#### 输出样例

```
168
```

#### 数据范围

- $n \leq 10^9$
- $m \leq 100$
- $a \leq 10^9$

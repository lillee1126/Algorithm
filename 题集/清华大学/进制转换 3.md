## 题目

#### 题目描述

将 $M$ 进制的数 $X$ 转换为 $N$ 进制的数输出。

#### 输入格式

输入的第一行包括两个整数：$M$ 和 $N$ $(2 \leq M, N \leq 36)$。

下面的一行输入一个数 $X$，$X$ 是 $M$ 进制的数，现在要求你将 $M$ 进制的数 $X$ 转换成 $N$ 进制的数输出。

#### 输出格式

输出 $X$ 的 $N$ 进制表示的数。

#### 输入样例

```
10 2
11
```

#### 输出样例

```
1011
```

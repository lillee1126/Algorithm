## 题目

#### 题目描述

输入两个长度不超过 $200$ 的正整数 $A$ 和 $B$，求 $A$ 和 $B$ 的乘积。

保证输入的正整数不会以 $0$ 开头，要求输出的正整数也不能以 $0$ 开头。

#### 输入格式

输入包含两行，每行一个正整数，分别为 $A$ 和 $B$。

#### 输出格式

输出一行，表示 $A$ 和 $B$ 的乘积。

#### 输入样例

```
123
456
```

#### 输出样例

```
56088
```

## 题目

#### 题目描述

输出 $100$ 到 $1000$ 之间能被 $5$ 和 $6$ 同时整除的数，输出格式为每 $10$ 个数为一行。

#### 输入格式

无输入

#### 输出格式

按题目意思输出，相邻两个数之间用空格隔开（注意每一行末尾没有空格）。

#### 输入样例
```
无
```

#### 输出样例
```
120 150 180 210 240 270 300 330 360 390
420 450 480 510 540 570 600 630 660 690
720 750 780 810 840 870 900 930 960 990
```

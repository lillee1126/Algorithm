## 题目

#### 题目描述

设节点定义如下

```

struct $Node$ {

    int $Element$; // 节点中的元素为整数类型

    struct $Node$ $*Next$; // 指向下一个节点

};

```

从键盘输入 $5$ 个整数，将这些整数插入到一个链表中，并按从小到大次序排列，最后输出这些整数。

#### 输入格式

输入 $5$ 个整数。

#### 输出格式

按题意输出。

#### 输入样例
```
5 3 4 2 1
```

#### 输出样例
```
1 2 3 4 5
```

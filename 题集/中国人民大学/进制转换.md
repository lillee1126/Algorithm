# 进制转换

- [在线评测](https://pgcode.cn/)

## 题目

#### 题目描述

给出一个十进制非负整数 $n$，请将该数转换为 $r$ 进制数并输出。 

$0 \leq n \leq 1000000000$，$2 \leq r \leq 16$。超出十进制的，用大写字母表示（例如，10用'A'，11用'B'，依此类推）。

#### 输入格式

输入共一行，包含两个整数 $n$ 和 $r$，表示需要转换的十进制数 $n$ 和目标进制 $r$。

#### 输出格式

输出共一行，表示转换后的 $r$ 进制数。

#### 数据范围

- $0 \leq n \leq 1000000000$

- $2 \leq r \leq 16$

#### 输入样例

```
126 16
```

#### 输出样例

```
7E
```

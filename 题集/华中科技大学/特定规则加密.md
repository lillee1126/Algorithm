# 特定规则加密

## 题目

#### 题目描述

输入一个占 32 比特位的十进制整数，设其二进制表示为`xxxx pppp xxxx eeee xxxx eeee xxxx eeee`（其中 ${p}$ 表示特定位置）。

加密规则：标记为 ${e}$ 的位左移 8 位，标记为 ${p}$ 的位右移 24 位，标记为 ${x}$ 的位不变。

输出加密后的十进制表示。


#### 输入格式

每行一个整数，直到文件结束。

#### 输出格式

每行输出加密后的十进制整数。

#### 数据范围

输入整数在 32 位有符号整型范围内。

#### 输入样例

```
1234
```

#### 输出样例

```
262864
```

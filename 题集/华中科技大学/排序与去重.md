# 排序与去重

## 题目

#### 题目描述

键盘输入一个整数 ${n}$ 和 ${n}$ 个数，将输入的数从小到大排序输出，然后去重（相同数字只保留一个）再输出。

#### 输入格式

第一行输入整数 ${n}$，第二行输入 ${n}$ 个整数。

#### 输出格式

第一行输出排序后的结果（用空格分隔），第二行输出去重后的结果（用空格分隔）。

#### 数据范围

${1 \le n \le 1000}$，输入数字在整型范围内。

#### 输入样例

```
5
6 3 2 3 2
```

#### 输出样例

```
2 2 3 3 6
2 3 6
```

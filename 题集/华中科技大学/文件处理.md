## 题目

#### 题目描述

文件操作及字符串处理。

输入一个源文件 $abc.c$ 的代码。

在 $abc.c$ 文件中有相当数量的注释，包括 $//$ 和 $/*...*/$ 两种形式的注释。

1、将输入的 $abc.c$ 文件的内容，将其显示在控制台上，(并为每行代码增加一个行号)。

2、使源代码中的 $//$ 类型的注释内容不显示在控制台中。

3、使源代码中的 $/*...*/$ 类型的注释内容不显示在控制台中。

4、不显示空行。

#### 输入格式

输入多行源代码

#### 输出格式

输出处理过的源代码

#### 输入样例
```
#include <stdio.h>
/*
这是一个求两数之和的程序
*/
int main() {
    int a, b;//定义
    //输入
    scanf("%d%d", &a, &b);
    /*  输出  */
    printf("%d\n", a + b);
    return 0;
}
```

#### 输出样例
```
1 #include <stdio.h>
2 int main() {
3     int a, b;
4     scanf("%d%d", &a, &b);
5     printf("%d\n", a + b);
6     return 0;
7 }
```

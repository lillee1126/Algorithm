# 回文字符串

## 来源

- [pgcode：华中科技大学计算机保研机试真题](https://gitcode.com/2301_81739397/pgcode)
- [在线评测](https://pgcode.cn/)

## 题目

#### 题目描述

给出一个长度不超过 $1000$ 的字符串，判断它是不是回文（顺读，逆读均相同）。

#### 输入格式

输入包括一行字符串，其长度不超过 $1000$。

#### 输出格式

可能有多组测试数据，对于每组数据，如果是回文字符串则输出 $Yes!$，否则输出 $No!$。

#### 输入样例
```
hellolleh
hellowor1d
```

#### 输出样例
```
Yes!
No!
```

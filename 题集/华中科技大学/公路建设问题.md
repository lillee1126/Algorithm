# 公路建设问题

## 题目

#### 题目描述

给定一个带权值的无向图，图中的边和顶点都有编号。

第一问要求将所有的边按权值排序输出。

第二问要求求出图的最小生成树，输出具体路径和最小代价。

#### 输入格式

第一行包含两个整数 $n$ 和 $m$，分别表示顶点数和边数。

接下来 $m$ 行，每行包含三个整数 $u$、$v$ 和 $w$，表示顶点 $u$ 和顶点 $v$ 之间有一条权值为 $w$ 的边。

#### 输出格式

第一问输出 $m$ 行，每行包含三个整数 $u$、$v$ 和 $w$，表示按权值排序后的边。

第二问输出最小生成树的路径和最小代价，具体格式见样例。

#### 输入样例
```
4 5
1 2 2
1 3 4
2 3 3
2 4 1
3 4 5
```

#### 输出样例
```
2 4 1
1 2 2
2 3 3
1 3 4
3 4 5
最小生成树路径：
2 4 1
1 2 2
2 3 3
最小代价：6
```

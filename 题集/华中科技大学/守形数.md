## 题目

#### 题目描述

守形数是这样一种整数，它的平方的低位部分等于它本身。

比如 $ 25 $ 的平方是 $ 625 $，低位部分是 $ 25 $，因此 $ 25 $ 是一个守形数。

 编一个程序，判断 $ N $ 是否为守形数。

#### 输入格式

输入包括 $ 1 $ 个整数 $ N $，$ 2 <= N < 100 $。

#### 输出格式

可能有多组测试数据，对于每组数据，

输出 $ "Yes!" $ 表示 $ N $ 是守形数。

输出 $ "No!" $ 表示 $ N $ 不是守形数。

#### 输入样例
```
25
4
```

#### 输出样例
```
Yes!
No!
```

# 打印日期

## 来源

- [pgcode：华中科技大学计算机考研复试机试真题](https://gitcode.com/2301_81739397/pgcode)
- [在线评测](https://pgcode.cn/)

## 题目

#### 题目描述

给出年分 $ y $ 和一年中的第 $ n $ 天，算出第 $ n $ 天是几月几号。

#### 输入格式

输入包括两个整数 $ y $ ($ 1 \leq y \leq 3000 $) 和 $ n $ ($ 1 \leq n \leq 366 $)。

#### 输出格式

可能有多组测试数据，对于每组数据，按 $ yyyy-mm-dd $ 的格式将输入中对应的日期打印出来。

#### 输入样例
```
2000 3
2000 31
2000 40
2000 60
2000 61
2001 60
```

#### 输出样例
```
2000-01-03
2000-01-31
2000-02-09
2000-02-29
2000-03-01
2001-03-01
```

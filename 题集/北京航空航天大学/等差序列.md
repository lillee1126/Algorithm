# 等差序列

## 题目

#### 题目描述

给定闭区间 $[a，b]$ ，要求输出连续的素数的等差序列，三个以上才算是序列，例如 $[100，200]$ 会输出 $151$ $157$ $163$

再例如输入 $[1，100]$ 会有两个等差序列，$3$ $5$ $7$ 和 $47$ $53$ $59$。

输出样式行末的空格保留。

#### 输入格式

输入两个正整数 $a$ 和 $b$，其中 $a$ 和 $b$ 小于等于 $10000$。

#### 输出格式

参考输出样例

#### 输入样例
```
141 400
```

#### 输出样例
```
151 157 163
167 173 179
199 211 223
251 257 263 269
367 373 379
```

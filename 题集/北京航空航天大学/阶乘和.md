## 题目

#### 题目描述

求 $ S_n = 1! + 2! + 3! + 4! + 5! + \ldots + n! $ 之值，其中 $ n $ 是一个数字。

#### 输入格式

输入一个 $ n $（$ n \leq 20 $）

#### 输出格式

输出 $ S_n $，$ S_n $ 可能超出 $ int $ 范围

#### 输入样例
```
5
```

#### 输出样例
```
153
```

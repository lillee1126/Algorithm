# 旋转矩阵

## 题目

#### 题目描述

任意输入两个 $9$ 阶以下矩阵，要求判断第二个是否是第一个的旋转矩阵，如果是，输出旋转角度 $(0、90、180、270)$，如果不是，输出 $-1$。

#### 输入格式

输入有多组数据。

每组数据第一行输入 $n$ $(1 \leq n \leq 9)$，从第二行开始输入两个 $n$ 阶矩阵。

每行两个数之间可以用任意个空格分隔。

行之间用回车分隔，两个矩阵间用任意的回车分隔。

#### 输出格式

判断第二个是否是第一个的旋转矩阵，如果是，输出旋转角度 $(0、90、180、270)$，如果不是，输出 $-1$。

如果旋转角度的结果有多个，则输出最小的那个。

#### 输入样例
```
3
1 2 3
4 5 6
7 8 9
7 4 1
8 5 2
9 6 3
```

#### 输出样例
```
90
```

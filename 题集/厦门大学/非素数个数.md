# 非素数个数

## 来源

- [pgcode：厦门大学计算机考研复试机试真题](https://gitcode.com/2301_81739397/pgcode)
- [在线评测](https://pgcode.cn/)

## 题目

#### 题目描述
求 ${a}$ - ${b}$ 之间的非素数个数。

特别的，${1}$ 也算作素数，区间是 ${[a, b]}$。

#### 输入格式
多组测试数据。

输入两个正整数 ${a}$，${b}$，其中 ${a<=b<=10^7}$。

#### 输出格式
输出答案。

#### 输入样例
```
1 10
1 100
```

#### 输出样例
```
5
74
```

## 题目

#### 题目描述

在进行数据传输时常使用字符串压缩算法节约资源，小C发现在他传输的字符串中有很多连续的字符，他基于这一点创造了以下压缩方法：

所有相同且连续的字符串将被压缩成 $“连续个数 + 原字符”$ 的形式，例如字符串 $“AaaaBC”$ 将被压缩为 $“1A3a1B1C”$，字符串 $“11111AB11”$ 将被压缩为 $“511A1B21”$。

请你帮小C完成压缩程序。

#### 输入格式

多组样例，第一行包含一个数字 $T$ 表示样例组数。

接下来每组样例占一行，保证输入字符串中只包含大小写字母、数字和空格。

需要处理到输入结束 $(EOF)$。

#### 输出格式

对于每一组输入，输出压缩结果。

#### 输入样例
```
3
333 444
    ABCD
TJU 1895
```

#### 输出样例
```
331 34
4 1A1B1C1D
1T1J1U1 11181915
```

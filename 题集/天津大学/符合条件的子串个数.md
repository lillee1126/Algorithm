# 符合条件的子串个数

## 题目

#### 题目描述

给定一个字符串 $S$ 和一个整数 $N$，要求统计所有满足以下条件的子串的个数：子串中每个符的数目不超过 $N$。

注意：是子串，不是子序列。

#### 输入格式

第一行输入一个整数 $T$ $(1 \leq T \leq 1000)$，表示测试数据的组数。

每组测试数据包含两行：

- 第一行是一个整数 $N$ $(1 \leq N \leq 100)$，表示子串中每个字符的数目不能超过的值。

- 第二行是一个字符串 $S$ $(1 \leq |S| \leq 10000)$，表示输入的字符串。

#### 输出格式

对于每组测试数据，输出一个整数 $M$，表示符合条件的子串的个数。

#### 输入样例

```
3
1
abc
1
abcabc
2
abcabc
```

#### 输出样例

```
6
15
21
```

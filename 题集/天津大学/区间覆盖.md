# 区间覆盖

## 来源

- [pgcode：天津大学计算机保研机试真题](https://gitcode.com/2301_81739397/pgcode)
- [在线评测](https://pgcode.cn/)

## 题目

#### 题目描述

给定 $n$ 个区间 $(l, r)$，每个区间会覆盖数轴上的对应的 $l \sim r$​ 位置（右端点不算），问数轴上被覆盖次数最多是多少。

#### 输入格式

多组样例，每组样例格式如下：

第一行包含一个整数 $n$，表示区间的数量。

接下来的 $n$ 行，每行包含两个整数 $l$ 和 $r$，表示一个区间的左右端点。

#### 输出格式

输出一个整数，表示数轴上被覆盖次数的最大值。

数据范围

$1 \leq n \leq 10000$

$0 \leq l < r \leq 10^9$

各个测试数据的 $n$ 之和不超过 $10000$

#### 输入样例

```
2
1 3
3 5
3
3 5
1 4
4 5
```

#### 输出样例

```
1
2
```

## 题目

#### 题目描述

建立一个求一元二次方程解的类（$a*x^2 + b*x + c = 0$），输入系数 $a$，$b$，$c$ 的值后打印出这个方程的解。

#### 输入格式

输入第一行为样例数 $m$，接下来 $m$ 行每行 3 个整数 $a$、$b$、$c$。

#### 输出格式

输出 $m$ 行，要求格式如下：若无解则输出 $-1$，若有单解则输出 $x=..$，若有两解则输出 $x1=...$，$x2=...$，小数在前，大数在后。具体参见样例，保留小数点后两位。

#### 输入样例
```
3
1 -3 2
1 -2 1
2 1 2
```

#### 输出样例
```
x1=1.00,x2=2.00
x=1.00
-1
```

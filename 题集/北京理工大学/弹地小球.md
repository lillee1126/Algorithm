# 弹地小球

## 题目

#### 题目描述

一个小球，从高为 $H$ 的地方下落，下落弹地之后弹起高度为下落时的一半，比如第一次弹起高度为 $H/2$，如此往复，计算从小球 $H$ 高度下落到第 $n$ 次弹地往返的总路程。

#### 输入格式

输入第一行为样例数 $m$，接下来 $m$ 行每行两个整数 $H$ 和 $n$，$n$ 不超过 $5$。

#### 输出格式

输出 $m$ 行，表示所求总路程，结果保留小数点后两位。

#### 输入样例
```
1
5 2
```

#### 输出样例
```
10.00
```

# 出现次数最多的数

## 来源

- [pgcode：重庆大学计算机考研复试机试真题](https://gitcode.com/2301_81739397/pgcode)
- [在线评测](https://pgcode.cn/)

## 题目

#### 题目描述
给定 $n$ 个正整数，找出它们中出现次数最多的数。 

如果这样的数有多个，请输出其中最小的一个。

#### 输入格式
第一行：一个正整数 $n$ $(1 \leq n \leq 1000)$，表示数字的个数 

第二行：$n$ 个整数 $s_1, s_2, ..., s_n$ $(1 \leq s_i \leq 10000, 1 \leq i \leq n)$，相邻的数用空格分隔

#### 输出格式
输出这 $n$ 个数中出现次数最多的数。如果这样的数有多个，输出其中最小的一个。

#### 数据范围
$1 \leq n \leq 1000$ 

$1 \leq s_i \leq 10000$

#### 输入样例
```
6
10 1 10 20 30 20
```

#### 输出样例
```
10
```

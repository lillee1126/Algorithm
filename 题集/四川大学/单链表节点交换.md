# 单链表节点交换

## 来源

- [pgcode：四川大学计算机考研复试机试真题](https://gitcode.com/2301_81739397/pgcode)
- [在线评测](https://pgcode.cn/)

## 题目

#### 题目描述

输入一个单链表，依次交换前 $2$ 个数，第 $3$、$4$ 个数，第 $5$、$6$ 个数，…，以此类推，直到操作完整个链表。

如果链表长度是奇数，则最后一个数不用操作。

输出交换之后的链表。

#### 输入格式

第一行包含整数 $n$，表示节点数量。

第二行包含 $n$ 个整数，表示每个节点的值。

#### 输出格式

共一行，输出交换后的链表。

#### 数据范围

$1 \leq n \leq 100$，

节点取值范围 $[1, 100]$。

#### 输入样例

```
5
1 2 3 4 5
```

#### 输出样例

```
2 1 4 3 5
```

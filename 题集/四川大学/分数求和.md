## 题目

#### 题目描述

有一分数序列：$ 2/1 $, $ 3/2 $, $ 5/3 $, $ 8/5 $, $ 13/8 $, $ 21/13 $, …… 求出这个数列的前 $ N $ 项之和，保留两位小数。

#### 输入格式

$ N $

#### 输出格式

数列前 $ N $ 项和

#### 输入样例
```
10
```

#### 输出样例
```
16.48
```

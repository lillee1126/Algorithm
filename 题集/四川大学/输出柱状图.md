# 输出柱状图

## 题目

#### 题目描述

根据输入的数据对应用 $*$ 打印出柱状图

#### 输入格式

第一行输入一个整数 $N$，其中 $N$ 不大于 $10$。

接下来输入 $N$ 个数，用空格间隔，每个数 $0 \leq a_i \leq 5$。

表示柱状图的高度。

#### 输出格式

按照样例格式输出，每两个数据中间有一个空列。

#### 输入样例

```
3
3 1 2
```

#### 输出样例

```
*
*   *
* * *
```

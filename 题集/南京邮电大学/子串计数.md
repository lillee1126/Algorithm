## 题目

#### 题目描述

给定字符串 $s$ 以及 $q$，求字符串 $s$ 中共计出现了多少次 $q$。

#### 输入格式

第一行包含一个整数 $n$，表示接下来的询问个数。
接下来 $n$ 行，每行包含两个字符串 $s$ 和 $q$，表示原字符串以及待查字符串，以空格间隔，题目保证字符串仅由大写字母构成。

#### 输出格式

输出共 $n$ 行，每行输出一个整数，表示字符串 $s$ 中共计出现了多少次 $q$。

#### 数据范围

$1 \le N \le 20$, $1 \le |s| \le 10^6$, $1 \le |q| \le 10^4$

#### 输入样例1

```
5
HAHAHA HA
WQN WQN
ADADADA ADA
BABABABABABABABABB BABABB
ADDAADAADDAAADAAD DAD
```

#### 输出样例1

```
3
1
3
1
0
```

#### 输入样例2

```
1
A Z
```

#### 输出样例2

```
0
```

#### 输入样例3

```
2
A AAA
AAAA AA
```

#### 输出样例3

```
0
3
```

## 题目

#### 题目描述

候鸟迁徙时遇到连续排列的山峰，其高度记录为数组 $h$。

候鸟会选择某座山峰作为起点平着飞行，直到遇到同等或更高的山峰才停下来。

飞行期间所有经过的山峰高度必须低于起点，且只能进行一次飞行。

平地（相邻高度相同）无法起飞。

若某个飞行路径延伸到最后的山峰，则计算到末尾的经过的山峰的数量。

请计算候鸟飞行中经过的山峰的最大数量。

若无法完成任何飞行，输出 $0$。

#### 输入格式

第一行一个整数 $n$，表示山峰数量。
第二行 $n$ 个整数 $h_i$，表示从左到右的山峰高度。

#### 输出格式

输出一个整数，表示候鸟飞行中经过的山峰的最大数量。

#### 数据范围

$2 \le n \le 10^6$, $1 \le h_i \le 10^9$

#### 输入样例1

```
11
2 3 2 1 2 5 5 5 3 2 5
```

#### 输出样例1

```
3
```

#### 输入样例2

```
5
5 4 3 2 1
```

#### 输出样例2

```
4
```

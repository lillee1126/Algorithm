# 名聚四海

## 题目

#### 题目描述

在著名的四海古城，每天游客都络绎不绝。

四海城由 $m$ 条横向街道和 $n$ 条纵向街道构成，将城市划分为 $(m+1)×(n+1)$ 个街区。

城市的参观入口修筑在城市的最西南角的街区，所有游客需要从城市最西南角的起点出发，前往最东北角的出口街区进行游览。

游客每一步只能向东或向北移动一个街区的距离。

![11](https://pgcode-image.oss-cn-beijing.aliyuncs.com/jnu/上机/nanjingyoudian2.png)

现在，四海城的文旅局正在指定旅游手册，他们想要计算出，游客们总共有多少种不同的路径可以到达出口？

#### 输入格式

两个整数 $m$ 和 $n$，表示横向和纵向的街道数量。

#### 输出格式

一个整数，表示不同的路径数目。
保证答案不超过 $2 \times 10^9$。

#### 数据范围

$1 \le m,n \le 30$。

#### 输入样例1

```
2 6
```

#### 输出样例1

```
28
```

#### 输入样例2

```
2 1
```

#### 输出样例2

```
3
```

#### 输入样例3

```
2 2
```

#### 输出样例3

```
6
```

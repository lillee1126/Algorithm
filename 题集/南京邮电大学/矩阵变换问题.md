# 矩阵变换问题

## 来源

- [pgcode：南京邮电大学计算机考研复试机试真题](https://gitcode.com/2301_81739397/pgcode)
- [在线评测](https://pgcode.cn/)

## 题目

#### 题目描述

给定一个 $n×m$ 的矩阵，对于 初始矩阵 中所有值为 $1$ 的元素，重置其 所在行列 的所有元素为 $0$，最后输出整个修改后的矩阵。

#### 输入格式

输入共包含 $1+n$ 行。
第一行包两个整数 $n$ 和 $m$，分别表示矩阵的长和宽。
接下来 $n$ 行，每行包含 $m$ 个整数，第 $i$ 行第 $j$ 个整数表示矩阵中坐标 $(i,j)$ 的值 $A_{i,j}$。

#### 输出格式

输出共包含 $n$ 行，每行包含空格分隔 $m$ 个整数。
第 $i$ 行第 $j$ 个整数表示修改后的矩阵中坐标 $(i,j)$ 的值 $A_{i,j}$。

#### 数据范围

$2 \le n,m \le 700$, $4 \le n \times m \le 180000$

#### 输入样例1

```
3 3
3 4 5
0 1 2
6 7 8
```

#### 输出样例1

```
3 0 5
0 0 0
6 0 8
```

#### 输入样例2

```
3 4
1 2 3 1
4 5 6 7
8 9 10 11
```

#### 输出样例2

```
0 0 0 0
0 5 6 0
0 9 10 0
```

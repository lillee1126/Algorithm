## 题目

#### 题目描述

对于任意给定的正整数 $n$，如果通过给从 $A$ 开始的 $n$ 个连续数字每个附加 $3$ 位数字，可以得到从 $B$ 开始的 $n$ 个连续数字的平方，则称 $A$ 和 $B$ 为平方朋友。

例如，给定 $n=3$，$A=73$ 和 $B=272$ 是平方朋友，因为 $73984=272^2$，$74529=273^2$，$75076=274^2$。

现在，对于任意给定的 $n$，要求找到所有满足 $A \leq MaxA$ 的平方朋友。

#### 输入格式

每个输入文件包含一个测试用例。

每个测试用例给出两个正整数：$n$（$\leq 100$）和 $MaxA$（$\leq 10^6$），如题目描述中所述。

#### 输出格式

输出所有满足 $A \leq MaxA$ 的平方朋友。

每对平方朋友占一行，格式为 $A$ $B$。

如果解不唯一，按 $A$ 的非递减顺序输出；如果仍有并列，按 $B$ 的递增顺序输出。

如果没有解，输出 $No Solution$。

#### 输入样例

```
3 85
```

#### 输出样例

```
73 272
78 281
82 288
85 293
```

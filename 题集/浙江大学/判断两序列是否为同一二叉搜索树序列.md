# 判断两序列是否为同一二叉搜索树序列

## 来源

- [pgcode：浙江大学计算机保研机试真题](https://gitcode.com/2301_81739397/pgcode)
- [在线评测](https://pgcode.cn/)

## 题目

#### 题目描述

判断两序列是否为同一二叉搜索树序列。

#### 输入格式

开始一个数 $n$，$(1 \leq n \leq 20)$ 表示有 $n$ 个需要判断，$n = 0$ 的时候输入结束。

接下来一行是一个序列，序列长度小于 $10$，包含 $(0 \sim 9)$ 的数字，没有重复数字，根据这个序列可以构造出一颗二叉搜索树。

接下去的 $n$ 行有 $n$ 个序列，每个序列格式跟第一个序列一样，请判断这两个序列是否能组成同一颗二叉搜索树。

#### 输出格式

如果序列相同则输出 $YES$，否则输出 $NO$。

#### 输入样例

```
2
567432
543267
576342
0
```

#### 输出样例

```
YES
NO
```

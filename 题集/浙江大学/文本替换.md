## 题目

#### 题目描述

给定 $n$ 组替换规则和一段英文文章，按照以下要求进行文本替换：

1. 替换时忽略大小写匹配，但保持原文的大小写风格。

2. 只替换完整单词，不能替换单词的一部分。

3. 如果原文单词首字母大写，替换后的单词首字母也要大写。

4. 特殊规则：独立的单词 "i"（前后都是空格或在句首句尾）要替换为 "I"。

#### 输入格式

第一行一个整数 $n$，表示替换规则的数量。

接下来 $n$ 行，每行两个字符串 $old$ 和 $new$，表示将单词 $old$（忽略大小写）替换为 $new$（但需根据原文大小写调整）。

最后一行输入一段英文文章 $s$（长度不超过 $1000$）。

#### 输出格式

输出替换后的文章。

#### 数据范围

$1 \leq n \leq 100$，$old$ 和 $new$ 的长度不超过 $20$，且只包含大小写字母。

文章 $s$ 的长度不超过 $1000$，且只包含大小写字母和空格。

#### 输入样例1

```
2
you
u
are
r
you are a student i think you are great
```

#### 输出样例1

```
u r a student I think u r great
```

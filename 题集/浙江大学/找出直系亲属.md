# 找出直系亲属

## 来源

- [pgcode：浙江大学计算机考研复试机试真题](https://gitcode.com/2301_81739397/pgcode)
- [在线评测](https://pgcode.cn/)

## 题目

#### 题目描述

如果 $A$，$B$ 是 $C$ 的父母亲，则 $A$，$B$ 是 $C$ 的 $parent$，$C$ 是 $A$，$B$ 的 $child$。

如果 $A$，$B$ 是 $C$ 的（外）祖父，祖母，则 $A$，$B$ 是 $C$ 的 $grandparent$，$C$ 是 $A$，$B$ 的 $grandchild$。

如果 $A$，$B$ 是 $C$ 的（外）曾祖父，曾祖母，则 $A$，$B$ 是 $C$ 的 $great-grandparent$，$C$ 是 $A$，$B$ 的 $great-grandchild$。

之后再多一辈，则在关系上加一个 $great-$。

#### 输入格式

输入包含多组测试用例，每组用例首先包含 $2$ 个整数 $n$（$0 \leq n \leq 26$）和 $m$（$0 < m < 50$）, 分别表示有 $n$ 个亲属关系和 $m$ 个问题。

然后接下来是 $n$ 行的形式如 $ABC$ 的字符串，表示 $A$ 的父母亲分别是 $B$ 和 $C$，如果 $A$ 的父母亲信息不全，则用 $-$ 代替。

例如 $A-C$，再然后是 $m$ 行形式如 $FA$ 的字符串，表示询问 $F$ 和 $A$ 的关系。

#### 输出格式

如果询问的 $2$ 个人是直系亲属，请按题目描述输出 $2$ 者的关系，如果没有直系关系，请输出 $-$。

具体含义和输出格式参见样例。

#### 输入样例
```
3 2
ABC
CDE
EFG
FA
BE
```

#### 输出样例
```
great-grandparent
-
```

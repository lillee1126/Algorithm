# 多项式标准形式

## 来源

- [pgcode：浙江大学计算机保研机试真题](https://gitcode.com/2301_81739397/pgcode)
- [在线评测](https://pgcode.cn/)

## 题目

#### 题目描述

给定一个次数为 $n$ 的多项式 $P(x)$，其标准形式为 $P(x) = a_n x^n + a_{n-1} x^{n-1} + \ldots + a_1 x + a_0$。

已知 $a_n = 1$ 且 $P(x)$ 的所有根 $\{r_1, r_2, \ldots, r_n\}$ 都是整数。

因此，$P(x)$ 可以表示为 $(x - r_1)(x - r_2) \ldots (x - r_n)$。

你的任务是根据给定的所有根，将 $P(x)$ 表示为标准形式。

#### 输入格式

每个输入文件包含一个测试用例。

对于每个测试用例，第一行给出一个正整数 $n$（$\leq 10$），表示 $P(x)$ 的次数。

接下来的一行给出 $n$ 个整数根，用空格分隔。

#### 输出格式

对于每个测试用例，在一行中输出系数 $a_i$（$i = n-1, \ldots, 0$）。

所有数字必须用一个空格分隔，行首或行末不得有多余的空格。

保证所有计算都在 int 范围内。

#### 输入样例

```
3
-1 4 -1
```

#### 输出样例

```
-2 -7 -4
```

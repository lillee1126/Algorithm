## 题目

#### 题目描述

浙江桐乡乌镇共有 $n$ 个人，请找出该镇上的前 $m$ 个大富翁。

#### 输入格式

每个用例首先包含 $2$ 个整数 $n$（$0 < n <= 100000$）和 $m$ ($0 < m <= 10$)。

其中: $n$ 为镇上的人数，$m$ 为需要找出的大富翁数。

接下来一行输入镇上 $n$ 个人的财富值。

#### 输出格式

请输出乌镇前 $m$ 个大富翁的财产数，财产多的排前面，如果大富翁不足 $m$ 个，则全部输出，每组输出占一行。

#### 输入样例
```
3 1
2 5 -1
5 3
1 2 3 4 5
```

#### 输出样例
```
5
5 4 3
```

# 字符游戏

## 题目

#### 题目描述

小明又得到了一个字符数组，每个字符都是 $a$-$z$ 其中的一个，你需要统计出每种字符出现的次数，他的幸运数字还是 $5$ 和 $7$，所以需要你按出现顺序输出其中个数是 $5$ 和 $7$ 的倍数的字符，并输出其个数。

#### 输入格式

第一行包含一个正整数 $n$ $(1 \leq n \leq 1000)$，第二行是一个含有 $n$ 个字符的字符数组

#### 输出格式

按题意输出

#### 输入样例
```
24
aaaaabbbbbbbbbbccddddddd
```

#### 输出样例
```
a 5
b 10
d 7
```

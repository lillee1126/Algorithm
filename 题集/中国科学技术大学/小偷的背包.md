# 小偷的背包

## 来源

- [pgcode：中国科学技术大学计算机考研复试机试真题](https://gitcode.com/2301_81739397/pgcode)
- [在线评测](https://pgcode.cn/)

## 题目

#### 题目描述

设有一个背包可以放入的物品重量为 $S$，现有 $n$ 件物品，重量分别是 $w_1$，$w_2$，$w_3$，...，$w_n$。

问能否从这 $n$ 件物品中选择若干件放入背包中，使得放入的重量之和正好为 $S$。

如果有满足条件的选择，则此背包有解，否则此背包问题无解。

#### 输入格式

第一行为物品重量 $S$（整数）；  第二行为物品数量 $n$，  第三行为 $n$ 件物品的重量的序列。

#### 输出格式

有解就输出”yes!“，没有解就输出”no!“。

#### 输入样例
```
20
5
1 3 5 7 9
```

#### 输出样例
```
yes!
```

# 运动会比赛日程安排

## 题目

#### 题目描述

某运动会设立 $M$ 个比赛项目，每个运动员（共 $N$ 个运动员）可以参加多个项目，每个项目的比赛时长相同。

试问如何安排比赛日程，既可以使同一运动员参加的项目不安排在同一单位时间进行，又使总的竞赛日程最短。

#### 输入格式

第一行包含两个整数 $N$ 和 $M$，分别表示运动员的数量和比赛项目的数量。

接下来的 $N$ 行，每行包含若干个整数，表示该运动员参加的比赛项目编号。

#### 输出格式

输出一个整数，表示最短的竞赛日程（单位时间数）。

#### 输入样例
```
3 4
1 2 3
2 3
3 4
```

#### 输出样例
```
3
```

# 今天是周几

## 题目

#### 题目描述
给定一个合法的日期，判断是周几，（周末输出周日）输入格式为年，月，日

例如：$1992$，$10$，$12$。输入保证合法。

#### 输入格式
一个合法的日期

#### 输出格式
判断是周几

#### 数据范围
输入日期合法

#### 输入样例
```
2020,1,12
```

#### 输出样例
```
星期日
```

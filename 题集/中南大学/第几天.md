## 题目

#### 题目描述

给定一个日期，输出这个日期是该年的第几天。输入数据格式为 YYYY/MM/DD 组成，具体参见输入示例。另外，所有输入数据是合法的。

对于每组输入数据，输出一行。

#### 输入格式

输入由多组数据组成。每组数据占一行，格式为 YYYY/MM/DD。

#### 输出格式

对于每组输入数据，输出一行，即该日期是该年的第几天。

#### 输入样例1

```
1985/01/01
```

#### 输出样例1

```
1
```

# 最小特征值之和

## 题目

#### 题目描述

给定一个长度为 $n$ 的数组 $A$ 和一个整数 $c$，$A$ 的特征值为前 $[n/c]$ 个小的元素之外的元素的和。

比如 $A = \{3, 1, 6, 5, 2\}$，$c = 2$，那么 $A$ 的特征值就为 $3 + 5 + 6 = 14$。

现要求将 $A$ 划分为若干个子数组，使得所有子数组的特征值之和最小，输出最小的特征值之和。

#### 输入格式

首先输入两个整数 $n$, $c$ $(1 \leq n, c \leq 10^6)$。

接下来输入 $n$ 个数字，代表数组 $A$ $(0 \leq a_i \leq 10^9)$。

#### 输出格式

输出最小特征值之和。

#### 输入样例
```
7 2
2 3 6 4 5 7 1
```

#### 输出样例
```
17
```

# 走路还是坐公交

## 题目

#### 题目描述
你收到通知被中南大学录取了，高兴的来到了长沙，很快你就来到了岳麓南路上，已知你的位置是 ${N}$，中南大学的位置是 ${K}$。

为了去中南大学，你有两种移动方式：走路或者坐公交。

走路：你可以从位置 ${X}$ 移动到 ${X+1}$ 或者 ${X-1}$，搭公交车：你可以从位置 ${X}$ 移动到 ${2X}$，每次走路或者搭公交车所需要的时间都是 1 分钟，你想尽快到达中南大学，所需的时间是多少呢？
#### 输入格式
多组数据。

对于每组数据，输入一行，分别是 ${N}$ 和 ${K}$（${0 \le N,K \le 100,000}$）。
#### 输出格式
对于每组数据，输出一行，所需时间。
#### 数据范围
${0 \le N,K \le 100,000}$
#### 输入样例
```
5 17
```
#### 输出样例
```
4
```

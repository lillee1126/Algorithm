# 二叉树的构造数量

## 来源

- [pgcode：南京大学计算机保研机试真题](https://gitcode.com/2301_81739397/pgcode)
- [在线评测](https://pgcode.cn/)

## 题目

#### 题目描述

给出一个二叉树的 $前序遍历序列$ 和 $后序遍历序列$ 的字符串，问通过这两个序列可以构造多少种不同的 $二叉树$。

#### 输入格式

输入包含两行：

- 第一行是二叉树的 $前序遍历序列$

- 第二行是二叉树的 $后序遍历序列$

#### 输出格式

输出一个整数，表示可以构造的不同 $二叉树$ 的数量。

#### 输入样例

```
ABDCEFG
DBEGFCA
```

#### 输出样例

```
4
```
